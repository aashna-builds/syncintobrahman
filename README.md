# syncintobrahman

A passcode-locked, explorable map. Draft.

- `lila-map-locked.html` desktop
- `lila-map-locked-mobile.html` phone

Download a file and open it in Safari or Chrome. Enter the passcode to unlock. The content is encrypted in the file and is only readable with the passcode; nothing is sent anywhere. Ask Aashna for the passcode.

Not tested: Safari on iPhone when the file is opened from the Files app. If your browser can't unlock the file, it says so.
